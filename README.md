# CODSOFT AI Internship Tasks

## Overview
This repository contains three projects completed as part of the CodSoft Artificial Intelligence Internship. These projects demonstrate basic Python programming, problem-solving, game AI, and recommendation system concepts.

## Task 1: Rule-Based Chatbot

**Description:**  
A simple chatbot that responds to user messages using predefined rules and conditions.

**Features:**
- Responds to greetings and simple questions.
- Provides basic information about Python.
- Uses predefined responses.
- Exits when the user types `bye`, `exit`, or `quit`.

**Technologies Used:** Python

**How to Run:**
```bash
python chatbot.py
```

## Task 2: Tic-Tac-Toe AI

**Description:**  
A Tic-Tac-Toe game where a human player competes against a computer. The computer uses the Minimax algorithm to choose its moves.

**Features:**
- Human vs. computer gameplay.
- Displays the game board.
- Checks winning and draw conditions.
- Uses the Minimax algorithm for computer decisions.

**Technologies Used:** Python

**How to Run:**
```bash
python tic_tac_toe.py
```

## Task 3: Movie Recommendation System

**Description:**  
A movie recommendation program that suggests movies based on genre similarity with the movie selected by the user.

**Features:**
- Contains a collection of movies and their genres.
- Compares movie genres.
- Recommends similar movies.
- Uses content-based filtering.

**Technologies Used:** Python

**How to Run:**
```bash
python recommendation_system.py
```

## Learning Outcomes
- Improved Python programming skills.
- Practiced conditional statements, loops, functions, and data structures.
- Learned the basics of game AI using Minimax.
- Understood content-based filtering for movie recommendations.

## Conclusion
These projects provided practical experience in Python programming and introductory AI concepts. They helped develop problem-solving skills and an understanding of rule-based systems, decision-making algorithms, and recommendation systems.
